# Взаимооценка вклада участников команды

Форма заполняется каждым участником индивидуально на контрольной точке КТ-6. Участник оценивает всех членов команды, **кроме себя**. Заполненные формы передаются преподавателю; команде они в исходном виде не раскрываются.

## 1. Форма оценки

Оценивающий: ____________________ Роль: ____________________

По каждому участнику выставляется оценка от 1 до 5 по четырём критериям.

| Критерий | Что оценивается | 1 | 3 | 5 |
|---|---|---|---|---|
| Вклад в артефакты | объём и качество результата по своей зоне ответственности | артефакты не подготовлены | подготовлены с замечаниями | подготовлены полно и качественно |
| Соблюдение сроков | готовность результата к контрольным точкам | систематические срывы | отдельные задержки | сроки соблюдены |
| Качество рецензирования | содержательность замечаний к чужим артефактам | не рецензировал | формальные замечания | находил существенные дефекты |
| Командное взаимодействие | участие в обсуждениях, реакция на запросы, передача контекста | не включён в работу | участвует по запросу | активно поддерживает работу команды |

| Участник | Вклад | Сроки | Рецензирование | Взаимодействие | Комментарий |
|---|:--:|:--:|:--:|:--:|---|
|  |  |  |  |  |  |
|  |  |  |  |  |  |
|  |  |  |  |  |  |
|  |  |  |  |  |  |

**Обязательный комментарий.** Для каждой оценки 1 или 2 приводится конкретный факт (пропущенная контрольная точка, несданный артефакт). Оценка без обоснования при расчёте не учитывается.

## 2. Расчёт коэффициента трудового участия

1. По каждому участнику собираются оценки коллег; из выборки исключаются максимальная и минимальная оценки, если оценивающих трое и более.
2. Рассчитывается средний балл участника **B** (от 1 до 5).
3. Взаимооценочная составляющая: **K₁ = 0,8 + 0,1 × (B − 3)**, ограниченная диапазоном 0,8–1,2.
4. Преподаватель определяет составляющую по зоне ответственности **K₂** (полнота артефактов роли и результат индивидуальной защиты) и составляющую по объективным следам работы **K₃** (коммиты, авторство и рецензирование pull request, протоколы), обе в диапазоне 0,8–1,2.
5. Итоговый коэффициент: **КТУ = 0,4 · K₁ + 0,4 · K₂ + 0,2 · K₃**.

Ограничения:

- КТУ не превышает 1,0, если участник не защитил свою зону ответственности индивидуально;
- расхождение между K₁ и K₂ более чем на 0,2 разбирается преподавателем на защите;
- при согласованном равном вкладе всех участников КТУ принимается равным 1,0 для всей команды.
