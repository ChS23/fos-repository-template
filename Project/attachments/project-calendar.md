# Календарный план проектной работы

Форма ведётся командой в репозитории и обновляется еженедельно. Отметка о прохождении контрольной точки ставится преподавателем.

## План-график

| КТ | Неделя | Результат | Ответственный | Плановая дата | Факт | Отметка |
|:--:|:--:|---|---|---|---|:--:|
| КТ-0 | 1 | Устав проекта, роли, установочная встреча с партнёром |  |  |  |  |
| КТ-1 | 2 | Карта заинтересованных сторон, Feasibility Study |  |  |  |  |
| КТ-2 | 3–4 | Техническое задание, спецификация требований, матрица трассируемости |  |  |  |  |
| КТ-3 | 5 | Архитектурное описание, ADR, обоснование вычислительной платформы |  |  |  |  |
| КТ-4 | 6 | План MLOps, карточка модели, модель угроз |  |  |  |  |
| КТ-5 | 7 | Рецензия на модель команды разработки, решение о вводе в эксплуатацию |  |  |  |  |
| КТ-6 | 8 | Сводный комплект, взаимооценка, предзащита |  |  |  |  |
