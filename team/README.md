## Вклад участников (CRediT)

Вклад описывается по таксономии CRediT. Ниже перечислены роли, выполненные при разработке фонда оценочных средств; персональное распределение указывается участниками в столбце «Исполнители».

| Роль CRediT | Содержание применительно к ФОС | Исполнители |
|---|---|---|
| Conceptualization (концепция) | постановка задачи дисциплины, выбор целевых ролей КРМ, определение сквозного кейса |  |
| Methodology (методология) | модель измерения, модель оценивания в условиях доступности генеративных моделей, система весов и порогов |  |
| Software (программное обеспечение) | инструменты сопровождения ФОС: валидатор согласованности, генератор данных, расчёт коэффициента трудового участия, проверка спецификации требований |  |
| Validation (валидация) | проверка согласованности индикаторов, часов, весов и рубрик; сверка нормативной базы |  |
| Formal analysis (формальный анализ) | разработка критериев и шкал оценивания, ориентиров для проверяющего |  |
| Investigation (исследование) | подбор и проверка стандартов, инструментальной базы, источников |  |
| Resources (ресурсы) | подготовка данных, модели и материалов заданий |  |
| Data curation (работа с данными) | формирование и профилирование учебного набора данных, спецификация вариантов |  |
| Writing — original draft (подготовка текста) | разработка РПД, контрольно-измерительных материалов, методических указаний |  |
| Writing — review & editing (редактирование) | внутреннее рецензирование материалов, согласование формулировок |  |
| Visualization (визуализация) | схемы архитектурных представлений, структура репозитория, презентационные материалы |  |
| Supervision (руководство) | научно-методическое руководство разработкой |  |
| Project administration (администрирование) | планирование работ, контроль сроков, сборка репозитория |  |
