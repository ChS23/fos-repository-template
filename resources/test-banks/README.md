# Банки тестовых заданий

Закрытые тестовые задания с автоматической проверкой в дисциплине не применяются. Текущий контроль проводится в форме защиты лабораторных работ, практических заданий и деловых игр; промежуточная аттестация — экзамен, включающий защиту проектной работы и теоретическую часть по билетам.

Выбор в пользу проверки понимания на защите обусловлен спецификой дисциплины: проверяемые артефакты являются документами, для которых тестовый контроль не подтверждает освоение результатов обучения.

| Банк | Назначение | Доступ | Дата проверки |
|---|---|---|---|
| Перечень вопросов к теоретической части экзамена (40 вопросов) | промежуточная аттестация | [Экзамен](../../Exam/README.md), раздел 6 | 17.07.2026 |
| Банк вопросов для защиты проектной работы | промежуточная аттестация | [Project/attachments/defense-questions.md](../../Project/attachments/defense-questions.md) | 17.07.2026 |

Практические задачи и ситуационные задания экзаменационных билетов относятся к закрытым материалам преподавателя и в репозитории не размещаются.

## Требования к добавлению

При включении тестовых заданий в последующие версии для каждого банка указываются темы, количество заданий, уровни сложности, правила выборки, ключи и порядок обновления.
