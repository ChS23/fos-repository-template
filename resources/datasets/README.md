Учебные данные дисциплины. Основной набор — синтетические данные продаж розничной сети, разработанные для дисциплины и используемые в КИМ-4.5 и проектной работе.

## 1. Происхождение и обоснование выбора

Набор сформирован генератором [`tools/generate_dataset.py`](../../tools/generate_dataset.py), разработанным для дисциплины. Использование синтетических данных вместо открытого набора обусловлено назначением КИМ-4.5: обучающийся должен обнаружить намеренно заложенный дефект модели, а для этого дефект должен быть **контролируемым, воспроизводимым и обновляемым**.

Открытые наборы данных этого не обеспечивают: дефект в них либо отсутствует, либо не поддаётся точному описанию в эталонном решении, а вариант задания невозможно сменить между потоками без потери сопоставимости оценивания. Генерация по фиксированному зерну даёт полную воспроизводимость и позволяет готовить неограниченное число вариантов.

## 2. Состав и профиль данных

Три хронологических среза, разбиение выполнено по времени.

| Срез | Строк | Дни | Доля промоакций | Медиана продаж | Назначение |
|---|--:|:--:|:--:|--:|---|
| `sales_train.csv` | 61 760 | 14–399 | 10 % | 76,1 | обучающая выборка |
| `sales_test.csv` | 16 000 | 400–499 | 10 % | 96,0 | отложенная выборка, использована в отчёте команды разработки |
| `sales_fresh.csv` | 6 400 | 500–539 | 45 % | 134,7 | свежий срез для проверки дрейфа |

**Размерность:** 20 торговых объектов четырёх форматов (`hyper`, `super`, `conv`, `disc`), 8 товарных категорий (`cat_A` … `cat_H`), 540 суток наблюдений.

**Признаки:** `day`, `store_id`, `store_format`, `category`, `dow`, `month`, `promo_flag`, `lag_7`, `lag_14`, `roll_28_mean`. Целевая переменная — `sales`.

**Заложенные закономерности:** годовая сезонность, недельная сезонность (рост в выходные), долгосрочный тренд, эффект промоакций, различная волатильность категорий, различие базового объёма продаж по форматам объектов.

## 3. Особенности, существенные для задания

Профиль срезов различается намеренно: доля промоакций в свежем срезе выше в четыре с половиной раза, а медиана продаж — выше на треть. Это воспроизводит типовую производственную ситуацию: модель обучена на одном режиме работы предприятия, а эксплуатируется в другом.

Обучающийся, ограничившийся проверкой на отложенной выборке (как это сделала «команда разработки» в приложенном отчёте), различие не обнаружит. Обнаружение требует прогона на свежем срезе и разбивки метрики по категориям.

Виды дефектов, поддерживаемые генератором, описаны в [спецификации](../../M4-quality-assurance/attachments/dataset-spec.md). Конкретный вид дефекта в выдаваемом варианте относится к закрытым материалам преподавателя.

## 4. Ограничения набора

Данные синтетические и не воспроизводят всех особенностей реальных розничных продаж: отсутствуют эффекты каннибализации между категориями, перебои поставок, локальные события. Набор пригоден для отработки контура верификации и приёмки модели и не пригоден для выводов о реальном рынке. Это ограничение сообщается обучающимся.

## 5. Воспроизведение и обновление

```bash
uv venv --python 3.12 && uv pip install numpy pandas scikit-learn
python tools/generate_dataset.py --defect drift --seed 20260717 --out out/
```

Для подготовки варианта на следующий поток изменяются зерно генератора и вид дефекта. Порядок обновления описан в [спецификации данных](../../M4-quality-assurance/attachments/dataset-spec.md).

## 6. Требования к добавлению новых наборов

Для каждого добавляемого датасета указываются источник, лицензия, состав признаков, целевая переменная, объём, ограничения, возможные смещения и рекомендуемое разбиение.
