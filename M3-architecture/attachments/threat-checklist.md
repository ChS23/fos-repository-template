# Перечень типовых угроз для архитектуры системы ИИ

Материал к части Г КИМ-3.5. Перечень используется для связывания архитектурных мер защиты с угрозами. Полная модель угроз разрабатывается в проектной работе.

## Угрозы по уровням системы

| Уровень | Угроза | Типовая архитектурная мера |
|---|---|---|
| **Данные** | Отравление обучающей выборки | контроль источников и целостности данных, версионирование наборов, проверка распределений перед обучением |
| | Несанкционированное изменение разметки | разграничение доступа к хранилищу разметки, журналирование изменений |
| | Утечка персональных или коммерческих данных | обезличивание, шифрование хранения и передачи, ограничение выгрузок |
| **Модель** | Кража модели через API | ограничение частоты запросов, контроль объёма выдачи, аутентификация потребителей |
| | Инверсия модели, извлечение обучающих данных | ограничение детализации ответа, отказ от выдачи оценок уверенности внешним потребителям |
| | Подмена артефакта модели | контроль происхождения и целостности артефакта, подпись и проверка при загрузке |
| | Неконтролируемое продвижение модели в эксплуатацию | реестр моделей, ворота качества, разграничение прав на продвижение |
| **Сервис инференса** | Состязательные примеры и атаки уклонения | валидация входных данных, контроль аномальных запросов, мониторинг распределения входов |
| | Отказ в обслуживании | ограничение нагрузки, резервный прогноз, таймауты |
| | Несанкционированный доступ к прогнозам | аутентификация и авторизация, разграничение областей видимости |
| **Конвейер MLOps** | Компрометация цепочки поставок и зависимостей | фиксация версий зависимостей, проверка происхождения артефактов сборки |
| | Утечка учётных данных и ключей | вынесение секретов из кода в защищённое хранилище |
| | Невозможность установить источник прогноза | журналирование обращений с фиксацией версии модели и набора признаков |

## Требования к оформлению части Г

Для каждой архитектурной меры указывается:

| Элемент архитектуры | Мера защиты | Угроза | Требование спецификации |
|---|---|---|---|
|  |  |  |  |

Мера, не связанная ни с одной угрозой, исключается из описания либо получает обоснование. Угроза уровня «Модель» или «Данные», не закрытая ни одной мерой, фиксируется как принятый остаточный риск с обоснованием.
